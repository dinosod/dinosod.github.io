数组指针

数组指针和指针数组的区别：

  • 指针数组：本质是数组，只是是指针类型的，be like: int* p[5]
  • 数组指针：本质是指针，类似于结构体指针，指向的是一个完整的数组（比如二维数组的某一行），be like: int (*p)[5]
  • 内存与大小区别：指针数组存多个指针，sizeof 返回数组总大小；数组指针只存单个地址，sizeof 返回指针大小

这里可能有点绕，为什么 *px 是数组首地址？我们知道 int *p = &a 这个句子里面 *p 是 a 的值，为什么 *px 就不是数组里的值呢？
关键是：px 指向的不是 int，而是有 2 个 int 的数组（px指向 int[2]），类型关系如下：

所以更准确地说，*px 本身是一个 int[2] 数组，只是数组在大多数表达式中会退化为指向首元素的指针，所以我们才说 *px 是数组的首地址。
在本例中，px 和 *px 的值相同，是因为它们都从同一块内存开头开始，但是他们的步长是不一样的，当涉及到加减时，px+1 跳过一整个小数组，也就是 2 个 int，*px+1 只跳过一个 int。
包括后面的计算也是，我觉得把这个数组指针视为大数组和小数组会比较便于理解，海东老师上课讲的根据数据类型计算字节，再换算成有几个 int，然后去数数有点太麻烦了，但还是得看一眼，毕竟计算数据类型的过程也有利于提升对指针的理解，接下来就来看看。

直接看 *(*(px+2)+1) 吧，这个懂了上面那个也没问题了。首先 px 是 int ()[2] 类型，去掉一个 * 是 int[2]，宽度为 2 个 int 也就是 8 字节，那 px+2 就是 +2×8=16 字节，也就是 4 个 int。然后 *(px+2) 的类型是 int[2]，他去参与 +1 运算你把它当成 int 用，那去掉一个 * 后为 int 型，宽度为 4 字节，即 1 个 int，那么就是从上一步的基础上往后再数 1 个 int 地址，总共走了 5 个 int，最后取值 arr[5] = 6。

补充：int *p[5] 与 int (*p)[5] 有什么区别？回到最开始介绍的问题上了，一个是指针数组一个是数组指针的区别。原因如下：

  • [] 的优先级高于 *，所以先组合成 p[5] 数组，再由 int * 说明数组存储的类型
  • () 的优先级高于 []，所以 * 先和 p 组合成指针，再由 int[5] 说明数组的宽度

  1. *() 与 [] 是可以互换的，也就是说：*(*(p+1)+2) 相当与 p[1][2]。那 *(p+1)[2] 是否一定等于 p[1][2] 呢？ 通过反汇编进行论证

    不一样，因为 [] 的优先级比一元 * 高，p[1][2] 应当等价于 (*(p+1))[2]，而 *(p+1)[2] 是相当于 *((p+1)[2])。

    所以 *(p+1)[2] == arr[6] == 7
