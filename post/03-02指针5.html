字符数组与字符串

字符串：

编译器会在最后面添加一个 00 作为字符串结束的标记
指针定义的字符串存在常量区，数组定义的会存在全局区（全局变量）/栈（局部变量）上

字符数组：

在使用字符数组来表示字符串的时候，要在结尾加上一个 ‘\0’ ，也可以不手动写让编译器自己加，但是一定要给这个空字符预留出位置，不留的话它就不知道该到哪里停，会导致缓冲区溢出等问题。当然如果字符数组只是用来存 char 类型数据的，那就无所谓了。

%s 的用法：打印一个字符串，直到内存为 0 为止

常量区

内存分布图：

哪个可以修改？哪个不能改？

编译都可以过，但是上面的不能改，下面的能改，为什么？
char* x = "china"; 不允许改，因为指针定义的字符串存在常量区，常量区不允许修改；
char y[] = "china"; 可以改，因为数组定义的字符串有一份在全局变量区的副本，修改也是修改的这个位置的副本。

哪个可以修改？哪个不能改？

先看第一句：

我们知道默认开辟的栈空间是 40h，加上这个后是 44h，也就是额外给 char* 类型的 x 开了一个位置，而这个位置存储的就是 china 字符串的地址，至于这个字符串自己本身，是存在常量区的

再看第二句：

发现 eax 里存的也是 china 这个字符串的首地址，演示第一句时那个首地址与这个一样，都是 0042201C，说明第二句这个定义方式也是存到了常量区，但是为什么这种写法就能改直接用指针指却改不了呢？看一下汇编

可以看到它是先把 chin 四个放到 eax 里，然后存到 [ebp-8] 上，还剩一个 a，又用了个 cx，存到 [ebp-4] 上。相比上一种，多了一步常量区字符串的拷贝。

我的理解是，字符串通常是存在常量区的，只是使用数组字符的时候，会把常量区里的字符串拷贝到数据段（全局变量）/堆栈（局部变量）这些可以修改的地方，修改时也是直接修改拷贝的这份副本，常量区原本的那份也是不会变的。

常见字符串操作

  • 返回字符串的长度
    int strlen (char* s) 返回值是字符串 s 的长度，不包括结束符 ‘\0’

  • 复制字符串
    char* strcpy (char* dest, char* src) 复制字符串 src 到 dest 中，返回指针为 dest 的值

    这样的操作会把 src 字符串里的 ‘\0’ 结束符也复制过去，因为 while 语句里面是先赋值再判断的，所以在遇到 0 停止之前，0 就已经赋值过去了

  • 字符串的拼接
    char* strcat (char* dest, char* src) 将字符串 src 添加到 dest 尾部，返回指针为 dest 的值

  • 字符串比较
    int strcmp (char* s1, char* s2) 一样返回 0，不一样返回 1
